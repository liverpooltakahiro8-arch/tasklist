算定式（年経費法 / 資本回収係数 CRF）

LCOH[円/kg] = ( CAPEX×CRF + 固定O&M + スタック交換費(年換算) ) ÷ 年間H2生産量
             + 電力単価×電力原単位 + 水費 ( − 補助金 − 副生酸素 )

CRF = r(1+r)^N / ((1+r)^N − 1)      r=割引率(WACC), N=設備寿命
年間H2[kg] = 定格電力[kW] × 年間稼働時間[h] ÷ 電力原単位[kWh/kg]
年間稼働時間 = 設備利用率 × 8,760h
スタック交換費 = Σ 各交換のNPV × CRF（寿命内で稼働時間に応じ周期交換）
円/Nm³ = 円/kg ÷ 11.13       （1kg-H2 ≒ 11.13 Nm³, 0℃/1atm, 密度0.0899kg/Nm³）

代表値の目安（プリセットの根拠）

  • 電力費が LCOH の 60〜75% を占めるのが一般的。稼働 5,000h/年未満では CAPEX 比率が 35% 超に。
  • 電力原単位：アルカリ ≈4.8 / PEM ≈5.0 / SOEC ≈3.8 kWh/Nm³（= 53 / 55 / 42 kWh/kg）。
  • システムCAPEX：アルカリ $800–1,400・PEM $1,000–2,000/kW。固定O&M は CAPEX の 1.5〜5%/年。
  • スタック寿命：60,000〜90,000h（SOEC は短め）。CAPEX の 19〜60% を占める。
  • 日本の供給コスト目標：2030年 30円/Nm³、2050年 20円/Nm³（現状 ≈100円/Nm³）。
