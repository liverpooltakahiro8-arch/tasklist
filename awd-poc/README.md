# AWD カーボンクレジット POC — データ記録シート

水稲の間断灌漑（AWD: Alternate Wetting and Drying）による CH₄ 削減を検証する
現地 POC 用のデータ記録テンプレートです。

- **対象方法論**: Verra **VM0042**（Improved Agricultural Land Management）
- **POC 主目的**: 実施可能性の確認（測定オペレーション・圃場の水理隔離・体制が回るか）
- **試験区**: コア 6 区 × 3 反復 = **18 プロット**

> POC 段階では「サイト固有 EF の確定」ではなく**実施可能性の確認**が主目的のため、
> 測定頻度は週 1 回＋落水イベント前後を基本とし、機材・人員の負荷を見極めます。
> 本格モニタリングへ移行する際は VM0042 / 適用モジュール（CH₄・N₂O の定量、
> 不確実性、QA/QC 要件）に合わせて頻度・反復・精度を引き上げてください。

## ファイル構成

| ファイル | 用途 | 記録頻度 |
|---|---|---|
| `01_flux_log.csv` | チャンバー測定（CH₄・N₂O フラックス）ログ | 測定毎（週1＋イベント時） |
| `02_plot_metadata.csv` | プロット別の固定情報（土壌・栽培・有機物） | 作付前に1回＋収量は収穫時 |
| `03_water_management_log.csv` | 水位・落水/再湛水イベント記録 | 観測毎（連続ロガー併用推奨） |

## 試験区マトリクス（水 × 有機物）

ベース＝連続湛水（CF）、改善＝AWD。有機物は SFo の表に対応。

| Plot 系統 | 水管理 | 有機物 | 設計 SFo | ねらい |
|---|---|---|---|---|
| `CF-O0` / `AWD-O0` | CF / AWD | なし | 1.0 | 水単独の純効果 |
| `CF-O1` / `AWD-O1` | CF / AWD | わら新鮮 4t | 5.0 | 水 × 高有機物（差が最大） |
| `CF-O3` / `AWD-O3` | CF / AWD | わら秋すき込み | 3.0 | 水 × 現地慣行 |

> 設計 SFo はご提示の線形版 `SFo = 1 + Σ(ROA × CFOA)`。
> VM0042 で採用する式（IPCC 本式は指数 `^0.59` 付き）に合わせて後で確定すること。

## 列の凡例（主要項目）

### 01_flux_log.csv
- `Plot_ID` … `{水}-{有機物}`（例 `AWD-O1`）、`Rep` … R1–R3
- `DAT` … 移植後日数（Days After Transplanting）
- `CH4_t0..t30_ppm` / `N2O_t0..t30_ppm` … チャンバー密閉 0/10/20/30 分のガス濃度
- `CH4_flux_mg_m2_h` / `N2O_flux_mg_m2_h` … 濃度の直線回帰から算出（mg/m²/h）
- `R2_CH4` / `R2_N2O` … 回帰の決定係数（**R² < 0.90 は要確認＝QC_flag**）
- `Water_level_cm` … 田面基準（＋湛水／−地下水位）、`Eh_mV` … 酸化還元電位
- `Event` … none / drain_start / re-flood / mid-season_drainage / final_drainage

### 02_plot_metadata.csv
- `ROA_t_ha_fresh` … 有機物施用量（生重）、`Dry_matter_pct` … 乾物率
- `ROA_t_ha_dry` … 乾物換算（わらは CFOA に乾物量を用いる）
- `Incorporation_date` / `Days_before_flooding` … すき込み〜湛水の日数（CFOA 区分の根拠）
- `AWD_threshold_cm` … 再湛水の地下水位閾値（安全 AWD は **−15cm**）

## 測定の必須セット（最低限）
1. **CH₄ と N₂O を同一チャンバーで同時測定**（AWD は N₂O 増の恐れ → CO₂eq の純削減を確認）
2. **水位の連続記録**（観測井／パニパイプ＋ロガー）＋落水/再湛水の日付
3. **有機物のすき込み日と乾物量**（SFo / CFOA の決定に必須）

## 運用メモ
- 測定時刻は午前（9–11時）に固定。数回は日内変動を取得して補正係数化。
- CF 区と AWD 区の間は**横浸透防止**（畦の遮水）。隔離が崩れると効果が消える。
- 反復は処理あたり最低 3（チャンバー空間変動が大きいため）。
