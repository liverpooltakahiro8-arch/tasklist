AWD（間断灌漑）とは

AWD（Alternate Wetting and Drying＝間断灌漑）は、水田を常に水で満たし続けるのではなく、 「水を張った状態」と「水を抜いて干した状態」を数日おきに繰り返す水管理方法です。 日本の慣行農法でいう「中干し」を計画的に行い、その期間を延長する取り組みも同じ考え方に含まれます。 水使用量の削減に加え、温室効果ガスであるメタンの排出を抑える効果があります。

なぜメタンが減るのか

水田に水を張り続けると、土の中が酸素のない状態（嫌気的）になり、そこで働く微生物（メタン生成菌）が 大量のメタン（CH₄）を発生させます。メタンはCO₂の数十倍の温室効果を持つガスです。
水を抜いて土を干す（落水）と土中に酸素が入り、メタンの発生が抑えられます。 この「干す」期間を設けることで、年間のメタン排出量をおおむね2〜3割削減できると報告されています （中干し7日間で約2〜3割減、収量への影響は0〜4%程度）。

ベースライン・削減量・クレジットの考え方

ベースラインプロジェクトを実施しなかった場合に出ていたであろう排出量。慣行（湛水）が基準。「これだけ出るはずだった」という比較の土台。
プロジェクト排出量AWD/中干しを実施した場合の排出量。ベースラインより小さくなります。
削減量ベースライン − プロジェクト排出量。この差が「減らせた量」。tCO₂e（CO₂換算トン）で表します。
カーボンクレジット削減量を第三者（国など）が認証し、売買できる単位にしたもの。日本では2023年に「水稲栽培における中干し期間の延長」がJ-クレジットの方法論として承認されました。本ツールはその事前検討（FS）用の概算です。

計算の流れ

日最低・最高気温 → サイン波で24時刻に補間 → 各時刻の温度 T → Q10^((T−25)/10) の平均 → f_T（温度補正） → ×EFc ×SFw ×SFo ×SFs → 日排出量(kgCH₄/ha) → ×面積 ×日数 → kgCH₄ → ×GWP÷1000 → tCO₂e

入力項目の説明

各項目をクリックすると詳しい説明が展開します。

毎日入力日最低気温（℃）例：22℃▼

何のための値か：その日の最も低い気温（通常は早朝の観測値）。

日最高気温と組み合わせて24時間分の気温カーブを自動計算します。気象庁のアメダスや現地の最低・最高温度計から取得できます。

なぜ重要か：気温が低いとメタン生成菌の活性が下がり、排出量は少なくなります。逆に夜温が高いままだと排出増につながります。日内変動を正確に捉えるために最低・最高の両方が必要です。

T(h) = 平均 + 振幅 × sin(2π(h−8)/24)
最低気温は早朝5時頃、最高気温は14時頃に出ると仮定してサイン波で補間します。
毎日入力日最高気温（℃）例：33℃▼

何のための値か：その日の最も高い気温（通常は午後2時前後の観測値）。

日最低気温と組み合わせて日内24時刻の温度カーブを自動計算します。暑い日ほど昼間の排出量が大きく増加するため、最高気温の精度がf_Tの精度に直結します。

目安：日本の水稲作期（5〜9月）では25〜36℃程度。気温が基準温度（25℃）を上回るほど排出係数への補正が大きくなります。

振幅 = (最高 − 最低) / 2
最低と最高の差が大きいほど日内変動が大きく、f_Tへの影響も増します。
毎日入力水位（cm）例：＋5（湛水） / 0 / −3（排水）▼

何のための値か：田面（地表面）を基準とした水位。プラスが湛水、ゼロ・マイナスが排水状態を示します。

このツールでは、水位が0cm以下の日が連続して3日以上続いた時点から「AWD排水」と自動判定し、SFw（水管理係数）を0.52に切り替えます。3日未満は湛水扱い（SFw=1.0）のままです。

なぜ3日か：IPCCや農林水産省の方法論では、土壌嫌気状態の解消に一定の落水期間が必要とされるため、単日の一時的落水はメタン抑制効果として認めない考え方が一般的です。

連続排水 ≥ 3日 → AWD排水（SFw=0.52）
連続排水 < 3日 → 湛水（SFw=1.0）
現地での水位計測は「水位管」（多孔管を地面に立てて水位を目視確認）を使うのが一般的です。
係数EFc（基準メタン排出係数）単位：kgCH₄/ha/day▼

何のための値か：「その地域・土壌・栽培条件での水田が、標準的な気温・湛水・有機物投入なしの条件で1日1haあたり何kgのメタンを出すか」を表す係数です。

地域ごとに異なり、気候・土壌・有機物量・灌漑水源などに依存します。IPCCのガイドラインやJ-クレジット方法論では国・地域別のデフォルト値が定められています。

いつ変更するか：対象圃場の地域・気候帯・土壌タイプが変わる時。現地測定値があればそちらを優先します。

日本_温暖 : 1.3
東南アジア高温 : 1.5
冷涼地域 : 1.0
値が大きいほどその圃場の基礎的なメタン発生ポテンシャルが高いことを意味します。
自動計算SFw（水管理係数）湛水=1.0 ／ AWD排水=0.52（初期設定）▼

何のための値か：水管理の形態がメタン排出に与える影響の大きさを表す倍率係数です。湛水（常時冠水）を1.0として、AWD排水時は何割になるかを示します。

AWD排水でSFwが0.52というのは、「落水することでメタン排出が湛水比で約52%（≒48%削減）になる」ことを意味します。

いつ手動変更するか：適用する方法論（J-クレジット等）が規定する値を使う必要がある場合、または現地計測に基づく値が得られた場合。通常はツールが水位から自動判定します。

SFw = 1.0（湛水）
SFw = SFw_AWD（排水）

削減率 ≈ 1 − SFw_AWD
例：1 − 0.52 = 48%
現地データモードでは水位計測値から自動判定。削減量想定モードでは期間ごとに「湛水/AWD」を選択して切り替えます。
係数SFw_base・SFp（ベースライン水管理・作付け前水管理）ベースラインの高さを決める係数▼

何のための値か：ベースライン（プロジェクトをやらなかった場合の慣行）の水管理を表す係数です。AWDによる削減量は「ベースライン排出 − プロジェクト排出」で決まるため、ベースラインが高いほど削減量（クレジット）も大きくなります。

SFw_base（作期中の慣行水管理）：ベースラインが常時湛水なら1.0。もし慣行ですでに1回落水しているなら0.71、複数回なら0.55と、ベースライン自体が下がります。慣行が湛水（1.0）であるほどAWDの削減余地が大きくなります。

SFp（作付け前の水管理）：IPCCでは作期の排出に、作付け前の水管理状態を掛け合わせます。作付け前に長期湛水していた圃場は土壌に有機物が蓄積し、作期のメタンが増えるため係数が大きくなります。作付け前に30日以上湛水すると2.41まで上がり、ベースライン排出（＝削減ポテンシャル）を引き上げられます。

使い方の例：「作付け前に意図的に湛水管理を行う圃場」をベースラインとして設定すると、SFpが1.0→1.9〜2.41となり、ベースライン排出が約2倍に。その分、AWD導入時の削減量も比例して大きくなります。※方法論・追加性の要件（そのベースラインが実態として妥当か）を必ず確認してください。

日排出（ベース）=
EFc × SFw_base × SFp
　× SFo × SFs × f_T

SFp 参考値：
湛水歴なし = 1.0
短期湛水 <180日 ≈ 1.22
作付前湛水 >30日 = 2.41
SFpはベースラインとプロジェクトの両方に掛かるため、削減量は SFp に比例して増加します（削減率自体は不変）。値はIPCC 2019 Refinement Vol.4 Ch.5 の既定値。地域・方法論の規定値を優先してください。
係数SFo（有機物係数）通常：1.0 ／ わら還元等で増加▼

何のための値か：有機物の投入状況がメタン排出に与える影響を補正する係数です。稲わらや堆肥などの有機物は、土中の嫌気的分解でメタンの材料（有機炭素）を増やします。

具体的な場面：稲わらをすき込む（わら還元）場合は1.2〜2.0程度に増加。緑肥や大量の堆肥投入でも増加します。何も有機物を入れない場合は1.0のまま。

注意：わら還元はメタン排出を大幅に増やす要因であり、AWD削減量の計算でも「ベースラインにわら還元分を含めるか」が重要な争点になります。

わら還元なし : 1.0
わら還元あり : 1.2〜2.0
堆肥投入 : 条件による
ベースラインとプロジェクト期間で有機物投入条件が同じなら相殺されます。変わる場合は両方に正しい値を設定してください。
係数SFs（土壌係数）通常：1.0▼

何のための値か：土壌の種類・性質がメタン排出に与える影響を補正する係数です。通常の水田土壌では1.0を使います。

変更が必要になる場面：酸性硫酸塩土壌（干拓地や旧湿地跡）・砂質土壌・重粘土など、特殊な土壌タイプで計測値から補正が必要と判断された場合。ほとんどの現場では1.0で問題ありません。

IPCCデフォルトでは通常の浸水条件の鉱質土壌を1.0の基準とし、特殊土壌に対して異なる係数が定義されています。

通常の水田土壌 : 1.0
特殊土壌 : 要検討
対象圃場が旧干拓地・干拓後の造成地・湿地転換地などの場合は専門家に確認することを推奨します。
係数Q10（温度感度係数）通常：2.0▼

何のための値か：気温が10℃上昇したとき、メタン生成菌の活性（＝排出量）が何倍になるかを表す係数です。

Q10=2.0 は「10℃上がると排出が2倍になる」という意味。これは多くの微生物反応で観測される典型的な値です。たとえば25℃基準で35℃になると排出が約2倍、15℃になると約半分になります。

計算への影響：このツールではQ10を使って「f_T（日内温度補正係数）」を計算します。夏の高温期は排出量がかなり増え、春先・秋は減ります。

変更する場面：感度分析（Q10=1.8〜2.5で結果の幅を見たい）や、特定の研究・方法論で異なる値が定められている場合。

f_T = Q10^((T−25)/10)
の24時刻平均

Q10=2, T=35℃ → ×2.0
Q10=2, T=25℃ → ×1.0
Q10=2, T=15℃ → ×0.5
温暖化が進むと排出量も増加するメカニズムがこのQ10に含まれています。
自動計算f_T（日内温度補正係数）自動計算 / 入力不要▼

何のための値か：その日の気温カーブ全体を通じたメタン生成活性の「平均的な倍率」を示す係数です。1日を通じた温度変化を積分して平均したものです。

日最低・最高気温から24時刻の温度T(h)を補間し、各時刻で Q10^((T(h)−25)/10) を計算。その24個の値を平均したものがf_Tです。

値の読み方：f_T > 1.0 なら「基準気温25℃より排出が多い」、f_T < 1.0 なら少ない。夏の暑い日は1.2〜1.5程度、春先は0.6〜0.8程度になることが多いです。

f_T = (1/24)×Σ Q10^((T(h)−25)/10)
（h=0〜23）

夏（均温29℃） ≈ 1.28
春（均温18℃） ≈ 0.69
f_Tが高いほど温度によって排出量が押し上げられています。同じ水管理でも夏と春で排出量が大きく異なるのはこの補正によるものです。
自動計算日排出量（kgCH₄/ha/day）自動計算 / 入力不要▼

何のための値か：その日、1haあたり何kgのメタンが排出されるかを示す最終的な日排出量です。

EFc（地域固有の基礎排出量）に、水管理（SFw）・有機物（SFo）・土壌（SFs）の3つの補正係数と、気温補正（f_T）を掛け合わせることで、実際の排出量に近い値を推計します。

この値の活用：これに面積を掛けてkgCH₄/日、さらにGWPを掛けてtCO₂e/日に変換。期間合計でプロジェクトの削減量が求まります。

日排出量 =
EFc × SFw × SFo × SFs × f_T

例：1.3×1.0×1.0×1.0×1.23

係数GWP（地球温暖化係数）AR5: 28 ／ AR6: 27 ／ AR4: 25▼

何のための値か：メタン（CH₄）の温室効果をCO₂と比較した場合の倍率です。CH₄の量をCO₂換算（tCO₂e）に変換するために使います。

メタンはCO₂に比べ温室効果が非常に強いガスですが、大気中での寿命が短い（約12年）ため、100年タイムスパンか20年タイムスパンかで値が変わります。

どれを選ぶか：J-クレジット制度等の公的方法論が指定する値に合わせます。現時点ではAR5の28が多くの国内制度で使われています（AR6の27への移行も進行中）。

tCO₂e = kgCH₄ × GWP ÷ 1000

AR5（100yr）: GWP = 28
AR6（100yr）: GWP = 27
AR5（20yr）: GWP = 86
AR4（100yr）: GWP = 25
GWPが大きいほど削減量（tCO₂e）も大きく計上されます。申請する制度・方法論に従って正しく選択してください。

※温度補間：最低気温は早朝5時頃、最高気温は14時頃に出ると仮定し、24時刻をなめらかに補間します。厳密な実測の時刻別気温がある場合は、観測値を用いる方が精度は高くなります。

計算式まとめ

時刻別気温T(h) = (最低+最高)/2 + (最高−最低)/2 × sin(2π(h−8)/24)　（h=0〜23時、各時刻を小数2桁に丸め）
f_T（温度補正）24時刻の Q10^((T−25)/10) の平均値
日排出量EFc × SFw × SFo × SFs × f_T　（kgCH₄/ha/日）
SFw（水管理）湛水 = 1.0 ／ AWD排水 = SFw_AWD（初期0.52）。現地データでは水位0cm以下が連続3日以上でAWD排水と自動判定
日CH₄量日排出量 × 面積（ha）　（kgCH₄/日）
tCO₂e換算kgCH₄ × GWP ÷ 1000
削減量ベースライン排出量 − プロジェクト（AWD）排出量
プロジェクト積算削減1作期の削減量 × プロジェクト期間（年）　※年1作を想定した概算
ご注意：本ツールは事前FS・概算を目的とした簡易モデルです。実際のクレジット申請・認証では、J-クレジット制度「水稲栽培における中干し期間の延長」などの各方法論が定める規定値・測定要件・モニタリング方法に従う必要があります。本ツールの数値はそのまま公式な削減量とはなりません。
